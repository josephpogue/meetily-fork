# Ask Next Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** During a live call, show Joseph a short, self-updating list of questions to ask the other side (plus up to two questions for himself), driven by an optional meeting brief he can edit mid-call.

**Architecture:** A third `claude -p` lineage (the ask lane) forks from the same trunk as the existing fast and deep answer lanes. Each ask turn sends only what changed (transcript delta, brief edit, dismissals) and gets back the whole replacement list, which a pure parser turns into stable-id items. Core wires it to utterance closes, a Refresh command, an Option-Q hotkey, and an `assistant-asks` event; the panel renders a persistent brief box and an "Ask next" section.

**Tech Stack:** Rust (Tauri 2, tokio, serde, uuid, chrono), Next.js 14 / React 18 / TypeScript, Tailwind + shadcn primitives, `bun test` for frontend unit tests, `cargo test` for Rust.

**Spec:** `docs/superpowers/specs/2026-10-09-ask-next-design.md` (builds on `docs/superpowers/specs/2026-09-01-live-assistant-design.md`). Read both before starting.

## Global Constraints

- Subscription only: every model call is a local `claude -p` spawn through the existing `Runner`. No paid APIs, no API keys.
- Nothing leaves the machine except through the claude CLI.
- The assistant suggests and never acts. The brief changes only when Joseph edits it or answers a For-you question.
- Assistant failures never touch recording or transcription. Every entry point catches its own errors.
- Ask lane model: `settings.fast_model` (default `claude-sonnet-5`), effort `medium`, no tools, `--safe-mode`. Not a user setting.
- Caps: at most 5 ASK items, at most 2 YOU (For-you) items.
- Ask lane system prompt lives in `frontend/src-tauri/src/assistant/prompts/ask.md`, embedded with `include_str!`.
- Panel label stays "Meeting brief (optional)", placeholder stays "What is this meeting about?".
- New hotkey: Option-Q refreshes the list.
- No em dashes in any prompt or UI text.
- Commit messages: concise and high level, no AI co-author lines (Joseph's rule).
- Work only in the worktree `../meetily-fork-worktrees/ask-next` on branch `enhance/ask-next`. Never commit to `main`.

## Decisions this plan makes where the spec is silent

- The ask lane forks right after `AnswerLanes::open` returns, not in parallel with the other two forks. Meeting start has no latency pressure, and this keeps `AnswerLanes` untouched apart from a `trunk_id()` getter.
- `AsksOut.state` gains a fourth value, `"unavailable"`, for the spec's "Ask next unavailable for this call" error state.
- For-you items serialize with an empty `why`, so the frontend uses one item type for both lists.
- The brief box is the source of truth: when a session closes, the current brief becomes the pending brief for the next recording, because the box still shows it. Joseph clears the box for a new meeting. Nothing is written to disk.
- Every ask turn also sends the still-open utterance (labeled "STILL SPEAKING"), because an utterance only closes when someone else speaks. Without it, pressing Refresh right after the other side stops talking would miss what they just said.

## Review Focus

1. Joseph presses Refresh right after the other side finishes a sentence and nobody has spoken since: the list must reflect that sentence (it is still an open utterance, not in `delta_since`). Pinned in Task 2 (`first_request_sends_delta_and_in_progress_text`).
2. The recording stops while an ask turn is in flight: the late reply must not overwrite the list or leave the section stuck on "thinking". Pinned in Task 2 (`close_drops_a_late_result`).
3. Joseph edits the brief while an ask turn is running: the edit must still reach the model on the next turn, not get marked as sent by the turn that started before it. Pinned in Task 2 (`brief_edit_during_a_turn_is_sent_on_the_next_turn`).
4. The model returns prose instead of the format: the previous list must stay and the failure must be visible. Pinned in Task 1 (`parse_rejects_prose`) and Task 2 (`failed_turn_keeps_previous_list_and_reports`).
5. Joseph dismisses a question and the model suggests a reworded version of it: it must not come back. Pinned in Task 1 (`build_drops_reworded_dismissed_question`) and Task 2 (`dismissed_item_is_removed_sent_once_and_never_returns`).

```rust
// assistant/ask_list.rs
//
// The Ask Next list: parse the ask lane's reply, keep item ids stable
// across refreshes so the panel does not flash, and drop anything Joseph
// dismissed. Pure functions, no I/O.

use std::collections::HashSet;

use serde::Serialize;

use super::card::content_words;

pub const MAX_ASKS: usize = 5;
pub const MAX_FOR_YOU: usize = 2;

/// Two questions count as the same item at or above this share of content
/// words, measured against the longer of the two.
const SAME_ITEM_OVERLAP: f64 = 0.6;

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct AskItem {
    pub id: String,
    pub question: String,
    /// Empty for a For-you item.
    pub why: String,
}

#[derive(Debug, Clone, Default, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct AskList {
    pub asks: Vec<AskItem>,
    pub for_you: Vec<AskItem>,
}

/// What one reply said, before ids are assigned.
#[derive(Debug, Clone, Default, PartialEq)]
pub struct RawList {
    pub asks: Vec<(String, String)>,
    pub for_you: Vec<String>,
}

/// `ASK: <question> | WHY: <reason>` and `YOU: <question>` lines, or the
/// single word NONE. Anything else is ignored; a reply with no usable line
/// and no NONE is unparseable and returns None, so the caller keeps the
/// previous list instead of blanking it.
pub fn parse(raw: &str) -> Option<RawList> {
    let mut out = RawList::default();
    let mut saw_none = false;
    for line in raw.lines() {
        let line = line.trim();
        let line = line.strip_prefix("- ").unwrap_or(line).trim();
        if line == "NONE" {
            saw_none = true;
        } else if let Some(body) = line.strip_prefix("ASK:") {
            let (question, why) = split_why(body);
            if !question.is_empty() && out.asks.len() < MAX_ASKS {
                out.asks.push((question, why));
            }
        } else if let Some(body) = line.strip_prefix("YOU:") {
            let question = body.trim().to_string();
            if !question.is_empty() && out.for_you.len() < MAX_FOR_YOU {
                out.for_you.push(question);
            }
        }
    }
    if out.asks.is_empty() && out.for_you.is_empty() && !saw_none {
        return None;
    }
    Some(out)
}

fn split_why(body: &str) -> (String, String) {
    match body.split_once('|') {
        Some((question, rest)) => {
            let rest = rest.trim();
            let why = rest.strip_prefix("WHY:").unwrap_or(rest).trim();
            (question.trim().to_string(), why.to_string())
        }
        None => (body.trim().to_string(), String::new()),
    }
}

pub fn same_item(a: &str, b: &str) -> bool {
    if a.trim().eq_ignore_ascii_case(b.trim()) {
        return true;
    }
    let wa = content_words(a);
    let wb = content_words(b);
    let longer = wa.len().max(wb.len());
    if longer == 0 {
        return false;
    }
    let shared = wa.intersection(&wb).count();
    shared as f64 / longer as f64 >= SAME_ITEM_OVERLAP
}

/// Turns a fresh reply into the list the panel shows: dismissed questions
/// (and rewordings of them) are dropped, and each surviving item takes the
/// id of the previous item it matches so React keeps it in place.
pub fn build(prev: &AskList, raw: RawList, dismissed: &[String]) -> AskList {
    let keep = |q: &str| !dismissed.iter().any(|d| same_item(d, q));
    let mut used: HashSet<String> = HashSet::new();
    let asks = raw
        .asks
        .into_iter()
        .filter(|(q, _)| keep(q))
        .map(|(question, why)| AskItem {
            id: carry_id(&prev.asks, &question, &mut used),
            question,
            why,
        })
        .collect();
    let for_you = raw
        .for_you
        .into_iter()
        .filter(|q| keep(q))
        .map(|question| AskItem {
            id: carry_id(&prev.for_you, &question, &mut used),
            question,
            why: String::new(),
        })
        .collect();
    AskList { asks, for_you }
}

fn carry_id(prev: &[AskItem], question: &str, used: &mut HashSet<String>) -> String {
    let id = prev
        .iter()
        .filter(|p| !used.contains(&p.id))
        .find(|p| same_item(&p.question, question))
        .map(|p| p.id.clone())
        .unwrap_or_else(|| uuid::Uuid::new_v4().to_string());
    used.insert(id.clone());
    id
}

/// The list in reply format, for the next turn's CURRENT LIST section.
pub fn render(list: &AskList) -> String {
    if list.asks.is_empty() && list.for_you.is_empty() {
        return "(empty)".to_string();
    }
    let mut lines = Vec::new();
    for a in &list.asks {
        if a.why.is_empty() {
            lines.push(format!("ASK: {}", a.question));
        } else {
            lines.push(format!("ASK: {} | WHY: {}", a.question, a.why));
        }
    }
    for y in &list.for_you {
        lines.push(format!("YOU: {}", y.question));
    }
    lines.join("\n")
}
```

```markdown
You are the planning half of a silent meeting assistant. Joseph is in a live call right now. You are not in the call. Nobody hears you. Your only output is a short list at the edge of his screen that he glances at between turns.

## Your job

The meeting brief is Joseph's goal for this call, in his own words. Work out what he still needs to learn from the other side to reach that goal, and list it as questions he can ask.

If there is no brief, or Joseph cleared it, infer the most likely purpose of the call from the transcript and work toward that.

Joseph is still learning how to run calls like this. Suggest the questions an experienced person in his seat would ask: the ones that uncover the real need, the constraints, who decides, the timeline, and what happens next, as far as they serve this brief.

## Channels

The transcript is labeled. `You:` is Joseph. `Them:` is everyone else. STILL SPEAKING is the latest utterance, which may be cut off mid-sentence.

## Rules

- Each question is one Joseph can say out loud exactly as written: short, open, one topic, plain conversational words.
- Rank by how much the answer moves Joseph toward the goal. Prefer a question that fits where the conversation is right now over one that would jerk it to a new topic.
- Drop a question as soon as the transcript answers it, even partly. Never list something Joseph already asked.
- Keep the exact wording of any question from CURRENT LIST that is still open. Only reword when the conversation has made the old wording wrong.
- Never suggest anything Joseph dismissed, or a rewording of it.
- WHY is a few words tying the question to the brief, not a sentence.
- Use a YOU line only when the brief is unclear in a way that changes which questions matter, for example whether pricing is in scope. These are questions for Joseph himself, not for the other side. At most two.
- No em dashes anywhere.

## Output contract

Write exactly this shape and nothing around it. No preamble, no headings, no code fences.

ASK: <question for Joseph to ask> | WHY: <a few words>
ASK: <question for Joseph to ask> | WHY: <a few words>
YOU: <question for Joseph himself>

At most five ASK lines and two YOU lines, most important first. If there is nothing worth asking right now, reply with exactly:

NONE
```

```rust
// assistant/ask_lane.rs
//
// Ask Next: a third claude lineage forked from the same trunk as the answer
// lanes. Each turn sends what changed since the last one (transcript delta,
// a brief edit, dismissals) and gets back the whole list of questions
// Joseph should still ask. At most one turn runs at a time. Requests that
// land meanwhile coalesce into one follow-up, fired through
// `AskHooks::rerun`, because only core holds the transcript.

use std::path::PathBuf;
use std::sync::{Arc, Mutex};

use serde::Serialize;

use super::ask_list::{self, AskItem, AskList};
use super::claude_cli::{ClaudeOutcome, ClaudeTurn, TurnHandle, NO_TOOLS};
use super::lanes::Runner;
use super::transcript::TranscriptLog;

pub const ASK_PROMPT: &str = include_str!("prompts/ask.md");

/// Higher than the fast lane's low: the quality of the questions is the
/// whole point, and nobody is waiting two seconds on this list.
const ASK_EFFORT: &str = "medium";

#[derive(Debug, Clone, PartialEq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct AsksOut {
    /// "idle" | "thinking" | "failed" | "unavailable"
    pub state: String,
    pub asks: Vec<AskItem>,
    pub for_you: Vec<AskItem>,
    pub updated_at: Option<i64>,
    pub brief: String,
}

pub type AskEmitFn = Arc<dyn Fn(AsksOut) + Send + Sync>;

#[derive(Clone)]
pub struct AskHooks {
    pub emit: AskEmitFn,
    /// Called once when a turn finishes and requests landed while it ran.
    pub rerun: Arc<dyn Fn() + Send + Sync>,
    pub on_error: Arc<dyn Fn(String) + Send + Sync>,
}

impl Default for AskHooks {
    fn default() -> Self {
        Self {
            emit: Arc::new(|_| {}),
            rerun: Arc::new(|| {}),
            on_error: Arc::new(|_| {}),
        }
    }
}

#[derive(Debug, Clone)]
pub struct AskConfig {
    pub cwd: PathBuf,
    pub model: String,
}

#[derive(Default)]
struct AskState {
    lane_id: Option<String>,
    cfg: Option<AskConfig>,
    unavailable: bool,
    /// Transcript cursor; advances only when a turn succeeds.
    cursor: usize,
    in_flight: bool,
    dirty: bool,
    failed: bool,
    list: AskList,
    updated_at: Option<i64>,
    brief: String,
    /// Bumped on every brief edit; `brief_sent` is the version the model
    /// last received. The trunk seed already carries the opening brief, so
    /// both start at 0.
    brief_version: u64,
    brief_sent: u64,
    /// Every question Joseph dismissed this session, for filtering.
    dismissed: Vec<String>,
    /// Dismissals the model has not been told about yet.
    dismissed_unsent: Vec<String>,
    /// Bumped by `close`; a turn that finishes under an older generation is
    /// dropped on the floor.
    generation: u64,
    live_runs: Vec<TurnHandle>,
}

impl AskState {
    fn snapshot(&self) -> AsksOut {
        let state = if self.unavailable {
            "unavailable"
        } else if self.in_flight {
            "thinking"
        } else if self.failed {
            "failed"
        } else {
            "idle"
        };
        AsksOut {
            state: state.to_string(),
            asks: self.list.asks.clone(),
            for_you: self.list.for_you.clone(),
            updated_at: self.updated_at,
            brief: self.brief.clone(),
        }
    }
}

pub struct AskLane {
    runner: Runner,
    hooks: AskHooks,
    state: Arc<Mutex<AskState>>,
}

impl AskLane {
    pub fn new(runner: Runner, hooks: AskHooks) -> Self {
        Self {
            runner,
            hooks,
            state: Arc::new(Mutex::new(AskState::default())),
        }
    }

    /// Forks the ask lineage off the seeded trunk. `trunk_id` is None when
    /// the trunk seed failed; the lane then reports "unavailable" for this
    /// call and every request is a no-op.
    pub async fn open(&self, trunk_id: Option<String>, cfg: AskConfig, brief: String) {
        {
            let mut s = self.state.lock().unwrap();
            s.brief = brief;
            s.cfg = Some(cfg.clone());
        }
        let lane_id = match trunk_id {
            Some(trunk) => {
                let turn = ClaudeTurn {
                    prompt: "Standing by. Reply with exactly the word READY.".to_string(),
                    cwd: cfg.cwd.clone(),
                    model: Some(cfg.model.clone()),
                    effort: Some(ASK_EFFORT.to_string()),
                    resume: Some(trunk),
                    fork: true,
                    append_system_prompt: Some(ASK_PROMPT.to_string()),
                    disallowed_tools: no_tools(),
                    partial: false,
                    safe_mode: true,
                    ..Default::default()
                };
                let outcome = self.run_bare(turn).await;
                match outcome.error {
                    Some(err) => {
                        log::warn!("assistant ask lane fork failed: {}", err);
                        None
                    }
                    None => outcome.session_id,
                }
            }
            None => None,
        };
        let out = {
            let mut s = self.state.lock().unwrap();
            s.unavailable = lane_id.is_none();
            s.lane_id = lane_id;
            s.snapshot()
        };
        (self.hooks.emit)(out);
    }

    async fn run_bare(&self, turn: ClaudeTurn) -> ClaudeOutcome {
        let state = self.state.clone();
        let register: Box<dyn FnOnce(TurnHandle) + Send> = Box::new(move |handle| {
            state.lock().unwrap().live_runs.push(handle);
        });
        (self.runner)(turn, Box::new(|_| {}), register).await
    }

    /// Runs one ask turn now, or marks a follow-up if one is already
    /// running. `force` runs even when nothing changed (the Refresh button);
    /// an automatic request with nothing new is a no-op.
    pub fn request(&self, log: &TranscriptLog, force: bool) {
        let (turn, generation, sent_version, sent_dismissed, new_cursor, out) = {
            let mut s = self.state.lock().unwrap();
            let (Some(lane_id), Some(cfg)) = (s.lane_id.clone(), s.cfg.clone()) else {
                return;
            };
            if s.in_flight {
                s.dirty = true;
                return;
            }
            let (delta, new_cursor) = log.delta_since(s.cursor);
            let in_progress = log.open_preview();
            let brief_changed = s.brief_version != s.brief_sent;
            let has_news = !delta.is_empty() || brief_changed || !s.dismissed_unsent.is_empty();
            if !force && !has_news {
                return;
            }
            let prompt = ask_prompt(
                &delta,
                &in_progress,
                brief_changed.then(|| s.brief.as_str()),
                &s.dismissed_unsent,
                &s.list,
            );
            s.in_flight = true;
            s.dirty = false;
            let turn = ClaudeTurn {
                prompt,
                cwd: cfg.cwd,
                model: Some(cfg.model),
                effort: Some(ASK_EFFORT.to_string()),
                resume: Some(lane_id),
                append_system_prompt: Some(ASK_PROMPT.to_string()),
                disallowed_tools: no_tools(),
                partial: false,
                safe_mode: true,
                ..Default::default()
            };
            (
                turn,
                s.generation,
                s.brief_version,
                s.dismissed_unsent.len(),
                new_cursor,
                s.snapshot(),
            )
        };
        (self.hooks.emit)(out);

        let runner = self.runner.clone();
        let state = self.state.clone();
        let hooks = self.hooks.clone();
        tokio::spawn(async move {
            let register_state = state.clone();
            let register: Box<dyn FnOnce(TurnHandle) + Send> = Box::new(move |handle| {
                register_state.lock().unwrap().live_runs.push(handle);
            });
            let outcome = (runner)(turn, Box::new(|_| {}), register).await;
            let parsed = match &outcome.error {
                None => ask_list::parse(&outcome.text),
                Some(_) => None,
            };

            let (out, rerun, error) = {
                let mut s = state.lock().unwrap();
                if s.generation != generation {
                    return;
                }
                s.in_flight = false;
                let error = match parsed {
                    Some(raw) => {
                        let next = ask_list::build(&s.list, raw, &s.dismissed);
                        s.list = next;
                        s.cursor = new_cursor;
                        s.brief_sent = sent_version;
                        s.dismissed_unsent.drain(..sent_dismissed);
                        s.updated_at = Some(chrono::Utc::now().timestamp_millis());
                        s.failed = false;
                        None
                    }
                    None => {
                        s.failed = true;
                        Some(
                            outcome
                                .error
                                .clone()
                                .unwrap_or_else(|| "Ask next could not read the model's reply.".to_string()),
                        )
                    }
                };
                (s.snapshot(), std::mem::take(&mut s.dirty), error)
            };
            (hooks.emit)(out);
            if let Some(err) = error {
                log::warn!("assistant ask turn failed: {}", err);
                (hooks.on_error)(err);
            }
            if rerun {
                (hooks.rerun)();
            }
        });
    }

    pub fn set_brief(&self, text: String) {
        let out = {
            let mut s = self.state.lock().unwrap();
            if s.brief == text {
                return;
            }
            s.brief = text;
            s.brief_version += 1;
            s.snapshot()
        };
        (self.hooks.emit)(out);
    }

    /// Removes the item at once and remembers it so it never comes back.
    /// False when no item has that id.
    pub fn dismiss(&self, id: &str) -> bool {
        let out = {
            let mut s = self.state.lock().unwrap();
            let removed = if let Some(pos) = s.list.asks.iter().position(|i| i.id == id) {
                s.list.asks.remove(pos)
            } else if let Some(pos) = s.list.for_you.iter().position(|i| i.id == id) {
                s.list.for_you.remove(pos)
            } else {
                return false;
            };
            s.dismissed.push(removed.question.clone());
            s.dismissed_unsent.push(removed.question);
            s.snapshot()
        };
        (self.hooks.emit)(out);
        true
    }

    /// Kills an in-flight turn and stops all further turns. The last list
    /// stays visible until the next session opens a fresh lane.
    pub fn close(&self) {
        let (handles, out) = {
            let mut s = self.state.lock().unwrap();
            s.generation += 1;
            s.in_flight = false;
            s.dirty = false;
            s.lane_id = None;
            (std::mem::take(&mut s.live_runs), s.snapshot())
        };
        for handle in handles {
            tokio::spawn(async move {
                handle.kill().await;
            });
        }
        (self.hooks.emit)(out);
    }

    pub fn snapshot(&self) -> AsksOut {
        self.state.lock().unwrap().snapshot()
    }

    /// The ASK questions still on the list, for the end-of-meeting note.
    pub fn open_asks(&self) -> Vec<String> {
        self.state
            .lock()
            .unwrap()
            .list
            .asks
            .iter()
            .map(|a| a.question.clone())
            .collect()
    }
}

fn no_tools() -> Vec<String> {
    NO_TOOLS.iter().map(|s| s.to_string()).collect()
}

fn ask_prompt(
    delta: &str,
    in_progress: &str,
    brief: Option<&str>,
    dismissed: &[String],
    current: &AskList,
) -> String {
    let mut out = String::new();
    if let Some(brief) = brief {
        if brief.trim().is_empty() {
            out.push_str("MEETING BRIEF: Joseph cleared the brief. Infer the purpose of the call from the transcript.\n\n");
        } else {
            out.push_str("MEETING BRIEF (updated, this replaces the earlier one):\n");
            out.push_str(brief.trim());
            out.push_str("\n\n");
        }
    }
    if !delta.is_empty() {
        out.push_str("NEW TRANSCRIPT since your last turn:\n");
        out.push_str(delta);
        out.push_str("\n\n");
    }
    if !in_progress.is_empty() {
        out.push_str("STILL SPEAKING (may be cut off mid-sentence):\n");
        out.push_str(in_progress);
        out.push_str("\n\n");
    }
    if !dismissed.is_empty() {
        out.push_str("Joseph dismissed these. Never suggest them again:\n");
        for q in dismissed {
            out.push_str("- ");
            out.push_str(q);
            out.push('\n');
        }
        out.push('\n');
    }
    out.push_str("CURRENT LIST:\n");
    out.push_str(&ask_list::render(current));
    out.push_str("\n\nReply with the full updated list in the ASK / YOU format, or NONE.");
    out
}
```

```rust
/// Ask lane hooks: every list change goes out as `assistant-asks`; a

fn make_ask_hooks(app: AppHandle<Wry>, handle: AssistantHandle) -> AskHooks {
    let rerun_handle = handle.clone();

    AskHooks {

                core.set_last_error(Some(msg));
```

```ts
/**
 * Pure helpers for the Ask next section of the assistant panel.
 */

/** A For-you answer becomes a new line at the end of the brief. */
export function appendBriefAnswer(brief: string, question: string, answer: string): string {
  const line = `- ${question.trim()} ${answer.trim()}`;
  const head = brief.trimEnd();
  return head ? `${head}\n${line}` : line;
}

export function formatUpdatedAgo(updatedAt: number | null, now: number): string {
  if (updatedAt === null) return '';
  const secs = Math.max(0, Math.round((now - updatedAt) / 1000));
  if (secs < 5) return 'updated just now';
  if (secs < 60) return `updated ${secs}s ago`;
  return `updated ${Math.floor(secs / 60)}m ago`;
}
```

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import { ChevronDown, ChevronRight } from 'lucide-react';
import { Textarea } from '@/components/ui/textarea';
import { useAssistant } from '@/contexts/AssistantContext';

/**
 * The meeting brief: optional, editable before and during the call, and
 * committed on blur. Folds to one line so it does not crowd the panel.
 * The backend's copy (sent with every assistant-asks event) wins whenever
 * it changes, unless Joseph is typing in the box at that moment.
 */
export function BriefBox() {
  const { asks, setBrief } = useAssistant();
  const [value, setValue] = useState('');
  const [expanded, setExpanded] = useState(true);
  const focused = useRef(false);

  useEffect(() => {
    if (!focused.current) setValue(asks.brief);
  }, [asks.brief]);

  return (
    <div className="border-b border-gray-200 p-3">
      <button
        type="button"
        onClick={() => setExpanded(!expanded)}
        className="mb-1 flex w-full items-center gap-1 text-xs font-medium text-gray-500"
      >
        {expanded ? <ChevronDown className="h-3 w-3" /> : <ChevronRight className="h-3 w-3" />}
        Meeting brief (optional)
      </button>
      {expanded ? (
        <Textarea
          value={value}
          onChange={(e) => setValue(e.target.value)}
          onFocus={() => {
            focused.current = true;
          }}
          onBlur={() => {
            focused.current = false;
            setBrief(value);
          }}
          placeholder="What is this meeting about?"
          className="min-h-[60px] text-sm"
        />
      ) : (
        <p className="truncate text-xs text-gray-400">{value.trim() || 'No brief'}</p>
      )}
    </div>
  );
}
```

- [ ] **Step 6: AskNext component**

Create `frontend/src/components/AssistantPanel/AskNext.tsx`:

```tsx
'use client';

import { KeyboardEvent, useEffect, useState } from 'react';
import { Loader2, RefreshCw, X } from 'lucide-react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { useAssistant } from '@/contexts/AssistantContext';
import { AssistantAskItem } from '@/types';
import { appendBriefAnswer, formatUpdatedAgo } from '@/lib/ask-next';

// How often the "updated 12s ago" stamp re-renders.
const STAMP_TICK_MS = 5000;

interface AskNextProps {
  disabled: boolean;
}

/**
 * Questions for Joseph to ask the other side, most important first, plus
 * up to two For-you questions about his own goal. Refreshes when someone
 * finishes speaking, on the Refresh button, and on Option-Q. Hidden until
 * a session opens; the last list stays visible after the call ends.
 */
export function AskNext({ disabled }: AskNextProps) {
  const { status, asks, refreshAsks, dismissAsk, setBrief } = useAssistant();
  const [now, setNow] = useState(() => Date.now());

  useEffect(() => {
    const timer = setInterval(() => setNow(Date.now()), STAMP_TICK_MS);
    return () => clearInterval(timer);
  }, []);

  const hasItems = asks.asks.length > 0 || asks.forYou.length > 0;
  if (!status.sessionOpen && !hasItems) return null;

  const thinking = asks.state === 'thinking';
  const failed = asks.state === 'failed';

  const answerForYou = async (item: AssistantAskItem, answer: string) => {
    await setBrief(appendBriefAnswer(asks.brief, item.question, answer));
    await dismissAsk(item.id);
  };

  let emptyMessage: string | null = null;
  if (asks.state === 'unavailable') {
    emptyMessage = 'Ask next unavailable for this call.';
  } else if (!hasItems && asks.updatedAt === null) {
    emptyMessage = 'Listening. Questions appear after the first exchange.';
  } else if (!hasItems) {
    emptyMessage = 'Nothing to ask right now.';
  }

  return (
    <div className="max-h-80 overflow-y-auto border-b border-gray-200 p-3">
      <div className="mb-2 flex items-center justify-between gap-2">
        <span className="text-xs font-medium text-gray-500">Ask next</span>
        <div className="flex items-center gap-2">
          <span className={failed ? 'text-xs text-amber-600' : 'text-xs text-gray-400'}>
            {failed ? 'refresh failed' : formatUpdatedAgo(asks.updatedAt, now)}
          </span>
          <Button
            variant="ghost"
            size="icon"
            className="h-6 w-6"
            onClick={refreshAsks}
            disabled={disabled || asks.state === 'unavailable'}
            title="Refresh (Option-Q)"
          >
            {thinking ? <Loader2 className="h-3.5 w-3.5 animate-spin" /> : <RefreshCw className="h-3.5 w-3.5" />}
          </Button>
        </div>
      </div>

      {emptyMessage ? (
        <p className="text-xs text-gray-400">{emptyMessage}</p>
      ) : (
        <ul className="flex flex-col gap-2">
          {asks.asks.map((item) => (
            <li key={item.id} className="group flex items-start gap-2">
              <div className="flex-1">
                <p className="text-sm text-gray-900">{item.question}</p>
                {item.why && <p className="text-xs text-gray-400">{item.why}</p>}
              </div>
              <button
                type="button"
                onClick={() => dismissAsk(item.id)}
                title="Dismiss"
                className="mt-0.5 text-gray-300 hover:text-gray-500"
              >
                <X className="h-3.5 w-3.5" />
              </button>
            </li>
          ))}
        </ul>
      )}

      {asks.forYou.length > 0 && (
        <div className="mt-3 border-t border-gray-100 pt-2">
          <span className="text-xs font-medium text-gray-500">For you</span>
          <ul className="mt-1 flex flex-col gap-2">
            {asks.forYou.map((item) => (
              <ForYouItem
                key={item.id}
                item={item}
                onAnswer={(answer) => answerForYou(item, answer)}
                onDismiss={() => dismissAsk(item.id)}
              />
            ))}
          </ul>
        </div>
      )}
    </div>
  );
}

function ForYouItem({
  item,
  onAnswer,
  onDismiss,
}: {
  item: AssistantAskItem;
  onAnswer: (answer: string) => void;
  onDismiss: () => void;
}) {
  const [value, setValue] = useState('');

  const handleKeyDown = (e: KeyboardEvent<HTMLInputElement>) => {
    if (e.key === 'Enter' && value.trim()) {
      e.preventDefault();
      onAnswer(value);
      setValue('');
    }
  };

  return (
    <li className="flex flex-col gap-1">
      <div className="flex items-start gap-2">
        <p className="flex-1 text-sm text-gray-900">{item.question}</p>
        <button
          type="button"
          onClick={onDismiss}
          title="Dismiss"
          className="mt-0.5 text-gray-300 hover:text-gray-500"
        >
          <X className="h-3.5 w-3.5" />
        </button>
      </div>
      <Input
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onKeyDown={handleKeyDown}
        placeholder="Answer, then Enter"
        className="h-7 text-xs"
      />
    </li>
  );
}
```
